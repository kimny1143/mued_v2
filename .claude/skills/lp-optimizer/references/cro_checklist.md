# CRO Audit Checklist

10項目×5段階評価で総合スコア算出。

## 1. Hero Section (15点満点)

### Headline (5点)
| Score | 基準 |
|-------|-----|
| 5 | 具体的ベネフィット＋数値＋ターゲット明確 |
| 4 | 具体的ベネフィットあり |
| 3 | ベネフィットあるが曖昧 |
| 2 | フィーチャー中心 |
| 1 | 意味不明/汎用的すぎ |

**Bad**: 「高機能な音楽制作ツール」
**Good**: 「1曲の制作時間を50%短縮するAI音楽アシスタント」

### Subheadline (5点)
- [ ] ヘッドラインを補完
- [ ] 「誰のため」が明確
- [ ] 「何が得られる」が明確

### Primary CTA (5点)
| Score | 基準 |
|-------|-----|
| 5 | アクション動詞＋価値＋目立つ＋Above the fold |
| 4 | 上記3つを満たす |
| 3 | 上記2つを満たす |
| 2 | 汎用的（「詳しくはこちら」） |
| 1 | 「送信」「Submit」等 |

---

## 2. Social Proof (5点)

| Score | 基準 |
|-------|-----|
| 5 | 具体的数値＋顔写真付き証言＋著名ロゴ |
| 4 | 具体的数値＋証言 |
| 3 | 証言あり（曖昧） |
| 2 | 「多くの方に」等の曖昧表現 |
| 1 | なし |

チェック項目:
- [ ] 具体的数値（「1,247人」not「1000人以上」）
- [ ] ターゲットに近い人物の声
- [ ] 名前・写真・役職
- [ ] 認知度のあるロゴ
- [ ] スクロール初期位置に配置

---

## 3. Benefits vs Features (5点)

| Score | 基準 |
|-------|-----|
| 5 | 全フィーチャーがベネフィット変換済み |
| 4 | 主要フィーチャーは変換済み |
| 3 | 一部変換 |
| 2 | ほぼフィーチャー列挙 |
| 1 | スペック羅列のみ |

### So What? テスト

| Feature | So What? | Benefit |
|---------|----------|---------|
| AI音声認識 | → | 鼻歌がそのまま楽譜に |
| クラウド保存 | → | どこでも続きから作曲 |
| 集中トラッキング | → | 最も創造的な時間帯を発見 |

---

## 4. Conversion Path (5点)

| Score | 基準 |
|-------|-----|
| 5 | CTAまで1-2ステップ、摩擦ゼロ |
| 4 | 3ステップ以内、軽微な摩擦 |
| 3 | 摩擦点あるが許容範囲 |
| 2 | 複雑なフォーム/多ステップ |
| 1 | コンバージョンパス不明確 |

チェック項目:
- [ ] CTAまでのステップ数（理想3以下）
- [ ] フォームフィールド必要最小限
- [ ] 入力エラーのフィードバック明確
- [ ] 進行状況の視覚化（複数ステップ時）

---

## 5. Visual Hierarchy (5点)

| Score | 基準 |
|-------|-----|
| 5 | 完璧なF/Zパターン、明確な優先順位 |
| 4 | 良好な視線誘導 |
| 3 | 基本的な構造あり |
| 2 | 要素が競合/散漫 |
| 1 | カオス |

チェック項目:
- [ ] 最重要メッセージが最も目立つ
- [ ] 読み進める順序が自然
- [ ] 空白の効果的使用
- [ ] CTAのコントラスト比十分

---

## 6. Copy Clarity (5点)

| Score | 基準 |
|-------|-----|
| 5 | 5秒で価値提案理解可能 |
| 4 | 10秒で理解可能 |
| 3 | 読めば理解できる |
| 2 | 専門用語多い/冗長 |
| 1 | 意味不明 |

チェック項目:
- [ ] 専門用語→平易な言葉
- [ ] 1段落3-4行以内
- [ ] 箇条書き活用
- [ ] アクティブボイス

---

## 7. Trust Elements (5点)

| Score | 基準 |
|-------|-----|
| 5 | プライバシー＋セキュリティ＋連絡先＋会社情報 |
| 4 | 上記3つ |
| 3 | 上記2つ |
| 2 | 1つのみ |
| 1 | なし |

---

## 8. Mobile Optimization (5点)

| Score | 基準 |
|-------|-----|
| 5 | CWV全合格＋優れたモバイルUX |
| 4 | CWV合格 |
| 3 | 基本的なレスポンシブ |
| 2 | モバイルで一部崩れ |
| 1 | モバイル未対応 |

チェック項目:
- [ ] タップターゲット48px以上
- [ ] テキスト16px以上
- [ ] 横スクロールなし
- [ ] 読み込み3秒以内

---

## 9. Message Match (5点)

| Score | 基準 |
|-------|-----|
| 5 | 流入元と完全一致＋期待超え |
| 4 | 高い一貫性 |
| 3 | 基本的な一貫性 |
| 2 | ややズレあり |
| 1 | 期待と乖離 |

---

## 10. Competitive Differentiation (5点)

| Score | 基準 |
|-------|-----|
| 5 | 明確な独自ポジション＋競合と明確な差 |
| 4 | 独自性あり |
| 3 | 差別化要素あるが弱い |
| 2 | 競合と類似 |
| 1 | 差別化なし |
