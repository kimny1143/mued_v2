# Copywriting Frameworks for Landing Pages

## AIDA Framework

### Attention（注目）
- 衝撃的な統計
- 意外な事実
- 痛み/課題の直接指摘
- 質問形式

```
例: 「作曲家の73%が『アイデアを形にする時間がない』と悩んでいます」
```

### Interest（興味）
- 共感を示す
- 問題の深刻さを掘り下げる
- ターゲットの状況を描写

```
例: 「せっかく浮かんだメロディも、DAWを開く頃には消えていませんか？」
```

### Desire（欲求）
- 解決策を提示
- ベネフィットを具体的に
- 使用後の理想の姿を描く

```
例: 「MUEDnoteなら、思いついた瞬間に声で記録。AIが自動で整理し、制作に集中できます」
```

### Action（行動）
- 明確なCTA
- 緊急性/希少性（乱用注意）
- リスク軽減（無料/返金保証）

```
例: 「今すぐ無料で始める → 最初の1曲は完全無料」
```

## PAS Framework

### Problem（問題）
```
「音楽制作のアイデアは浮かぶのに、いざDAWに向かうと何も出てこない」
```

### Agitation（煽り）
問題を放置した場合の結果（煽りすぎ注意）
```
「このままでは、あなたの才能は永遠にファイルの中で眠ったまま」
```

### Solution（解決）
```
「MUEDnoteは、あなたの創造性を逃さない。
思いついた瞬間を音声で記録し、AIが制作プロセスを加速」
```

## 4Ps Framework

### Picture（描写）
```
「締め切りに追われず、純粋に音楽を楽しめる日々。
作りたいときに作り、休みたいときに休む」
```

### Promise（約束）
```
「MUEDnoteを使えば、あなたの制作フローは劇的に変わります」
```

### Prove（証明）
```
「既に1,247人のプロデューサーが制作時間を平均47%短縮」
```

### Push（後押し）
```
「7日間無料トライアルで、あなた自身の目で確かめてください」
```

## Headline Formulas

### 1. How to型
```
How to [達成したいこと] without [避けたいこと]

例: 「DAWスキルなしで、プロ級のデモを作る方法」
```

### 2. 数字型
```
[数字] Ways to [ベネフィット]

例: 「制作時間を半減させる5つの習慣」
```

### 3. Secret型
```
The Secret of [ターゲット] Who [成功結果]

例: 「週1曲リリースを続けるプロデューサーの秘密」
```

### 4. Contrarian型
```
Why [一般常識] Is Wrong (And What to Do Instead)

例: 「DAWを開く前に曲を完成させる非常識な方法」
```

### 5. Specific型
```
[ターゲット向け]: [具体的ベネフィット]

例: 「作曲初心者向け: 最初の1曲を3日で完成させる」
```

## CTA Best Practices

### Do（推奨）
- アクション動詞で始める
- 価値を含める
- 具体的にする
- 1ページ1つの主要CTA

### Don't（避ける）
- 「送信」「クリック」等の汎用語
- 複数の等価値CTAの並列
- 曖昧な表現

### Before/After Examples

| Bad | Good |
|-----|------|
| 送信 | 無料で始める |
| 詳しくはこちら | デモを見る（2分） |
| 登録 | 今すぐ作曲を試す |
| Submit | Get My Free Template |
| Learn More | See How It Works |
| Sign Up | Start Creating Free |

## MUEDnote専用フレーズ集

### Pain Points
- 「アイデアが浮かんでも、DAWを開く頃には忘れてる」
- 「制作と事務作業の切り替えで集中が途切れる」
- 「どの時間帯が一番創造的かわからない」
- 「メモがバラバラで、あとで探せない」

### Benefits（So What?変換済み）
- 音声メモ → 「思いついた瞬間を逃さない」
- AI文字起こし → 「後から検索できる」
- 集中トラッキング → 「最もクリエイティブな時間を発見」
- タグ整理 → 「必要なときにすぐ見つかる」

### Social Proof Templates
```
「MUEDnoteを使い始めて、週の制作時間が12時間→8時間に。
余った時間でミックスに集中できるようになった」
— [名前], [肩書/実績]
```

```
「[具体的な数値の改善]が起きた。
[その結果得られた感情/成果]」
— [信頼性を高める属性]
```
