# MUEDnote コンセプト・フレーミング整理

**作成日**: 2026-01-06
**目的**: MUEDnoteの本質とMVPポジショニングの混同を防ぐ

---

## 1. 二層構造

MUEDnoteは「本質的価値」と「MVPキャッチ」の二層で設計されている。

```
┌─────────────────────────────────────────────┐
│  表層: MVPキャッチ                           │
│  「集中力維持・脳疲労防止の休憩トラッカー」    │
│  - Hooキャラクターによる親しみやすいUX         │
│  - ポモドーロ/スタンダード/ディープワーク      │
│  - 4時間/日の自然な制限                       │
└─────────────────────────────────────────────┘
                     ↑
          ユーザーが最初に触れる層

┌─────────────────────────────────────────────┐
│  深層: 本質的価値                            │
│  「音楽制作中の思考・判断の可視化」           │
│  - なぜその判断をしたかの記録                 │
│  - 違和感・納得感の痕跡                       │
│  - 創作プロセスの振り返り                     │
└─────────────────────────────────────────────┘
```

---

## 2. 正しいフレーミング

### NG: 「練習トラッカー」

| 誤解 | 問題点 |
|-----|--------|
| 練習時間を積み上げる | MUEDnoteは「練習」を支援するアプリではない |
| 上達が目的 | 目的は思考の記録・振り返り |
| 繰り返し訓練 | 対象は創作作業（一回性の判断） |

### OK: 「集中セッション + 休憩トラッカー」

| 正しい理解 | 説明 |
|-----------|------|
| 集中セッション | 時間を区切った創作作業の単位 |
| 休憩トラッカー | 脳疲労防止のための休憩リマインド |
| 思考ログ | セッション中の独り言を記録 |

---

## 3. Hooキャラクターの役割

**Hoo** = フクロウ型AIアシスタント

### デザイン意図

- 見守る存在（押し付けない）
- 適度な休憩を促す（命令ではない）
- 親しみやすさ（継続利用の動機）

### メッセージトーン

```
NG: 「休憩してください」（命令的）
OK: 「お疲れさま！軽く深呼吸してね」（提案的）

NG: 「集中時間が長すぎます」（否定的）
OK: 「しっかり休もう」（肯定的）
```

## 4. データの意味

### muednote_mobile_sessions

| フィールド | 「練習」解釈（NG） | 正しい解釈 |
|-----------|------------------|-----------|
| durationSec | 練習時間 | セッション時間（作業枠） |
| sessionMemo | 練習メモ | 振り返りメモ（気づき） |
| status | 練習完了 | セッション完了 |

### muednote_mobile_logs

| フィールド | 「練習」解釈（NG） | 正しい解釈 |
|-----------|------------------|-----------|
| text | 練習中のつぶやき | 思考の断片（判断の痕跡） |
| timestampSec | 練習経過時間 | セッション内タイミング |

## 5. ダッシュボード可視化の方針

### MVP段階（休憩トラッカーキャッチ）

| 可視化 | 目的 |
|-------|------|
| 累計時間（日/週/月） | 作業量の把握 |
| 週間カレンダー | セッション日の可視化 |
| モード使用傾向 | 集中パターンの発見 |
| 最近のセッション一覧 | 履歴確認 |

### Phase 2以降（思考の可視化）

| 可視化 | 目的 |
|-------|------|
| セッションごとのログ閲覧 | 思考の振り返り |
| キーワード抽出 | 傾向の発見 |
| 判断パターン分析 | 自己理解 |

---

## 6. MUED理念との接続

> 「出力はAI、判断と欲は、人間。」

MUEDnoteは「判断」を記録するツール。

- AIが出力する（文字起こし、分析）
- 人間が判断する（何を残すか、何に気づくか）

「練習」は反復による上達を目指す概念であり、MUEDの理念とは異なる。
MUEDnoteが記録するのは「一回性の創作判断」である。

## 7. 開発時の注意

### コード・UIでの表現

| NG | OK |
|----|-----|
| 練習時間 | セッション時間 / 作業時間 |
| 練習履歴 | セッション履歴 |
| 練習を始める | セッションを始める / 作業を始める |
| 練習カレンダー | セッションカレンダー |

### 変数名・コメント

既存コードに「practice」「練習」が残っている場合は、
リファクタリング時に「session」「セッション」に統一すること。
