# サブスク戦略 & プロダクト位置づけ

**策定日**: 2026-02-25
**ステータス**: 決定済み・実装待ち

---

## 1. 背景

MUEDnote / MUEDear の App Store リリース後、以下の戦略的判断を行った。

- LP を2つの無料 iOS アプリ訴求に簡素化（実施済み）
- サブスクモデル、MUEDlobe の位置づけ、課金の壁を再定義

---

## 2. プロダクト別方針

### MUEDear
- **現状維持**。リワード広告モデル
- サブスク・課金は導入しない

### MUEDnote
- サブスクモデルを導入する
- App Review で手こずったのは「初回起動時のログイン強制」が原因であり、サブスクモデル自体は問題ない
- 無料でコア機能を使わせた上で、付加価値利用時にサインインを促す導線にする

### MUEDlobe
- **スタンドアロン製品を廃止**
- MUEDnote Premium の機能として統合
- 認知プロファイルは「Hoo の個人化エンジン」として位置づける

---

## 3. MUEDnote 課金階層

### 設計原則

- **課金の壁は「量」ではなく「質」に置く**
- ターン数制限は廃止。Basic / Premium とも Hoo 会話は無制限
- Basic → Premium の差は「Hoo の個人化の有無」
- Basic の時点でデータを蓄積し、Premium 開始時に Hoo が即座に個人化される体験を作る

### 階層詳細

| | Free | Basic | Premium |
|--|------|-------|---------|
| **Hoo** | 音に反応して跳ねるだけ | Haiku 汎用会話（無制限） | Haiku 個人化会話（無制限） |
| **記録** | ローカル保存のみ | クラウド同期 + DAW ログ | 同左 |
| **データ活用** | なし | 見える化（練習時間、作業傾向の可視化） | 深い分析 + Hoo プロンプトへの反映 |
| **Whisper 分析** | なし | あり（バッチ処理） | あり |
| **MUEDlobe** | なし | なし | アンロック（認知プロファイル測定） |

### 課金動機の流れ

```
Free: Hoo かわいい、跳ねてる → アプリに愛着
  ↓
Basic: Hoo と話したい → 月額低め
  ↓  （会話ログ・DAW ログが蓄積される）
  ↓
Premium: Hoo にもっと自分を分かってほしい → 月額高め
  ↓
Premium 初日: 蓄積データで Hoo が即座に個人化 → 「覚醒」体験
```

---

## 4. Hoo の個人化仕組み（Premium）

### Basic の Hoo（汎用プロンプト）
- 誰に対しても同じシステムプロンプト
- 音楽制作の一般的なアシスタント

### Premium の Hoo（個人化プロンプト）
- ユーザーの練習データ、DAW ログ傾向、認知プロファイルをシステムプロンプトに注入
- 同じ Haiku モデルでも、コンテキストの差で体験が大きく変わる

個人化に使うデータソース:
1. **Hoo 会話ログ**（Basic から蓄積）
2. **DAW ログ**（Basic から蓄積、macOS Hub → OSC → API → DB）
3. **Whisper 文字起こし**（Basic から蓄積、バッチ処理）
4. **タイムスタンプ同期データ**（音声ログ × DAW ログの結合、Basic から蓄積）
5. **MUEDlobe 認知プロファイル**（Premium でアンロック）

### Hoo の発話タイミング
- 作業中: **喋らない**（跳ねるだけ）
- 休憩タイマー発動時 / セッション終了後: **振り返りモードで会話**
- Whisper はバッチ処理（録音終了後）。リアルタイム処理は不要

---

## 5. MCP 従量課金（将来）

- iOS では当面 MUEDnote UI 経由が一択（MCP クライアントが iOS で普及していないため）
- MCP 経由の API 消費はデスクトップ向けの将来オプション
- API キー + クレジット残高で制御
- サブスクプランに月 N 回分のクレジットを含める設計も可能
- **現時点では優先度低。iOS サブスクを先に確立する**

---

## 6. 検証が必要な仮説

| 仮説 | 検証方法 | タイミング |
|------|---------|-----------|
| Basic の DAW ログ見える化でユーザーが価値を感じるか | ログ蓄積後のユーザー行動観察 | Basic リリース後 |
| 蓄積データ量と Premium Hoo の個人化品質の関係 | プロンプト実験、A/B テスト | Premium 開発中 |
| 「Hoo 覚醒」体験が Premium への転換動機として十分か | コンバージョン率測定 | Premium リリース後 |
| ターン数制限なしでの Haiku コスト | Basic ユーザーの平均ターン数モニタリング | Basic リリース後 |

---

## 7. 決定事項まとめ

| 項目 | 決定 |
|------|------|
| MUEDear | 現状維持。広告モデル |
| MUEDnote Free | Hoo は跳ねるだけ。ローカル保存 |
| MUEDnote Basic | Hoo 汎用会話（Haiku、無制限）。クラウド同期 + DAW ログ + Whisper。データの見える化 |
| MUEDnote Premium | Hoo 個人化。蓄積データ + 認知プロファイルで覚醒。MUEDlobe アンロック |
| MUEDlobe | スタンドアロン廃止。Premium 機能として統合 |
| ターン数制限 | 廃止。Basic / Premium とも無制限 |
| Basic → Premium の壁 | 量ではなく質（個人化の有無） |
| MCP 従量課金 | 将来のデスクトップ向け。今は優先度低 |

### 追加決定事項（ロードマップ議論より）

| 項目 | 決定 |
|------|------|
| 課金方式 | Web（Stripe）で完結。App Store 課金は使わない |
| iOS 上の Hoo | Basic 以上で会話可能。作業中は跳ねるだけ、休憩/セッション終了後に振り返り会話 |
| Whisper 処理 | バッチ（録音終了後）。リアルタイムは不要。Basic から解放 |
| DAW ログ | macOS Hub（Swift）→ OSC → API → DB。Basic から解放 |
| ログ同期 | 音声文字起こし × DAW 操作ログをタイムスタンプで結合 |
| App Review 戦略 | Free はログインなし維持。Basic 機能タップ時にサインイン。Sign in with Apple 必須。最小変更で審査 → 通過後に順次機能追加 |
