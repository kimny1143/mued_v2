# MuHorse 企画書

## 概要

| 項目 | 内容 |
|------|------|
| ゲーム名 | MuHorse（ミューホース） |
| 所属 | MUEDear 内ゲームモード |
| コンセプト | 「同じにしてみろ」コンプレッサー再現ゲーム |
| 着想 | バスケのHORSE + Learning Synths的インタラクティブUX |
| 差別化 | SoundGymにない「能動的パラメータ操作型」耳トレ |

## ゲーム構造

### 基本ルール

1. お手本音源が流れる（コンプ処理済み）
2. プレイヤーは同じ原音に対してコンプのパラメータを操作
3. 制限時間内にお手本と同じかかり方を再現する
4. 一致度をスコアリング

### 「当てる」と「合わせる」の違い

| 従来モード（MuComp） | MuHorse |
|----------------------|---------|
| 処理済み/未処理を聴き分ける | パラメータを操作して再現する |
| 受動的（選択） | 能動的（操作） |
| 正解/不正解の二値 | 一致度のグラデーション |
| 知識の確認 | スキルの訓練 |

## 難易度設計

### Easy

## コンプレッサーモデル

既にMUEDearに実装済みの4アルゴリズムをそのまま使用。

| モデル | 実機参考 | キャラクター |
|--------|----------|-------------|
| FET | 1176系 | 速い、アグレッシブ |
| OPT | LA-2A系 | 滑らか、ナチュラル |
| Tube | Fairchild系 | 温かい、倍音付加 |
| VCA | 33609系 | クリーン、正確 |

### Hardモードでの種類判別ポイント

プレイヤーが耳で判断すべき差異：

- FET：アタックの速さ、パンチ感
- OPT：ゆるやかなゲインリダクション、自然な追従
- Tube：偶数倍音の付加、低域の膨らみ
- VCA：色付けの少なさ、リニアな反応

## UI設計

### Learning Synthsから盗むもの

- スクロール/操作と音の変化がリアルタイムに連動
- パラメータの意味を「読む前に触って体感する」導線
- ビジュアルフィードバック（波形やゲインリダクションの可視化）

### ゲーム画面構成

```
┌─────────────────────────────────┐
│  [お手本を聴く]    [自分の音を聴く] │  ← A/B切替
│                                 │
│  ┌─ コンプUI（実機風） ────────┐  │
│  │                           │  │
│  │   INPUT ◉    OUTPUT ◉    │  │
│  │   ATTACK ◉   RELEASE ◉   │  │
│  │   RATIO ◉    THRESHOLD ◉ │  │
│  │                           │  │
│  └───────────────────────────┘  │
│                                 │
│  ゲインリダクション可視化メーター   │
│                                 │
│  ⏱ 00:30    一致度: 72%         │
│                                 │
│  [SUBMIT]                       │
└─────────────────────────────────┘
```

### 実機風UIの方針

- 各コンプモデルごとに異なるノブレイアウト
- FET：縦並び、クリック式Ratio
- OPT：Peak Reduction + Gainの2ノブ
- Tube：左右対称の大型ノブ
- VCA：横並び、LEDメーター
- 版権回避：実機名は使わず、レイアウトと操作感で「わかる人にはわかる」

## スコアリング

### 一致度の算出

各パラメータの差分を重み付けして総合スコア化。

| パラメータ | 重み | 理由 |
|-----------|------|------|
| コンプ種類（Hardのみ） | 40% | 根本的な判断 |
| Ratio | 20% | 圧縮量の根幹 |
| Attack | 15% | トランジェントへの影響大 |
| Release | 10% | 比較的聴き取りにくい |
| Threshold | 15% | かかり具合の深さ |

### ランク

| スコア | ランク |
|--------|--------|
| 95-100% | Golden Ear |
| 85-94% | Sharp Ear |
| 70-84% | Good Ear |
| 50-69% | Learning |
| 0-49% | Keep Trying |

## 出題ロジック

### AI出題（基本）

- 毎回ランダムにコンプ種類・パラメータを組み合わせ
- 難易度に応じてパラメータ範囲を制限
- 楽曲ジャンルによる傾向変化（キック→FETアグレッシブ、ボーカル→OPTナチュラル等）

### 将来拡張：ユーザー間対戦

- ユーザーAが設定を作る → ユーザーBが再現する
- HORSEそのもの：「この設定当ててみろ」
- ランキング/マッチメイキング

## MUEDear内でのポジション

```
MUEDear ゲームラインナップ

[MuFreQ]  EQ周波数当て        ← 入門
[MuComp]  コンプ有無の判別     ← 基礎
[MuHorse] コンプ再現チャレンジ  ← 応用 ★NEW
[MuRush]  EQタイムアタック     ← スピード
[MuVerb]  リバーブ聴き分け     ← 空間系
[MuWidth] ステレオ幅           ← 空間系
```

MuCompで「コンプの有無がわかる」→ MuHorseで「コンプを自分でかけられる」への自然な導線。
