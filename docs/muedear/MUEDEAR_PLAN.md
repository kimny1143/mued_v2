# MUEDear 開発計画書

## 概要

| 項目 | 内容 |
|------|------|
| アプリ名 | MUEDear（ミュードイヤー） |
| コンセプト | SoundGymの無料モバイル版 |
| ターゲット | 全世界のプロデューサー / DTMer / エンジニア |
| 言語 | 英語ベース（日本語対応あり） |
| 差別化 | SoundGym有料ゲームがリワード広告で無料 |
| マスコット | Hoo（フクロウ） |
| キャッチコピー | "Train Your Golden Ears" |

### なぜフクロウ（Hoo）なのか

- フクロウは**動物界最高の聴力**を持つ
- 左右非対称の耳で音源を三角測量（0.00003秒の時間差を検出）
- 60cm先の雪の下のネズミも音だけで捕獲可能
- 「黄金の耳（ゴールデンイヤー）」を育てるアプリの象徴として最適

## プロジェクト構成

既存MUEDプロジェクト内に追加：

```
mued/
├── muednote/         ← 既存（制作ログアプリ）
├── muedear/          ← 新規追加（耳トレアプリ）
└── ...
```

作成コマンド：
```bash
cd mued/
npx create-expo-app muedear
```

### MUEDエコシステムでの位置づけ

```
[MUEDnote]              [MUEDear]
制作中に使う             制作外で使う
休憩・ログ               耳トレ
「耳を休める」           「耳を鍛える」
```

※ 別アプリとして独立。コンセプトの矛盾を避ける。
※ 将来的に統合要望があれば検討。

## ゲームラインナップ

MVP時点で5ゲーム。全てリワード広告モデル。

| ゲーム | カテゴリ | 内容 | 参考元（SoundGym） |
|--------|----------|------|---------------------|
| MuFreQ | EQ | ブーストされた周波数を当てる | Peak Master（無料） |
| MuComp | ダイナミクス | どちらがコンプかかってる？（2択） | Dr. Compressor（無料） |
| MuRush | EQ | 60秒タイムアタック | EQ Cheetah（有料） |
| MuVerb | 空間系 | 違うリバーブを探す（3択） | Reverb Wizard（有料） |
| MuWidth | 空間系 | ステレオ幅を当てる | Stereohead（有料） |

### 命名規則

「Mu」はMUEDブランドから。将来的にglasswerksのプラグインラインナップとしても展開可能な命名。

## 収益モデル

### MVP版（シンプル構成）

| 項目 | 内容 |
|------|------|
| 基本プレイ | 1日5回まで無料 |
| 追加プレイ | リワード広告視聴で解放 |
| 課金 | なし（MVP時点） |

### 広告方式

**リワード広告のみ採用**（インタースティシャル広告は使わない）

| 理由 | 内容 |
|------|------|
| 音ゲーとの相性 | 強制広告は音量制御不能で耳に悪影響 |
| UX | ユーザーが自分のタイミングで広告を見る |
| 収益性 | リワード広告はCPM高め |

### MVPのフロー

```
[ゲームプレイ]（1日5回まで）
    ↓
[回数切れ]
    ↓
[「広告を見てプレイ継続」ボタン]
    ↓
[ユーザーがボタン押す]（音量調整の猶予あり）
    ↓
[リワード広告再生]
    ↓
[追加プレイ解放]
```

### 将来拡張（MVP後）

| フェーズ | 追加機能 |
|----------|----------|
| Phase 2 | ライフ制導入、アイテム課金（ライフ回復、ヒント等） |
| Phase 3 | 音源パック販売、追加ゲーム |
| Phase 4 | MUEDサブスク連携（広告除去、無制限プレイ、分析機能） |

### 将来の収益3本柱

| 収益源 | 内容 |
|--------|------|
| リワード広告 | 広告見てプレイ回数回復 |
| アイテム課金 | ライフ、ヒント、音源パック等 |
| サブスク | MUEDサブスクで全解放 + 分析機能 |

### 将来のMUEDエコシステム構想

```
[MUEDnote]          [MUEDear]
制作中に使う         制作外で使う
休憩・ログ           耳トレ
    ↓                   ↓
    └─── MUEDサブスク ───┘
         両方プレミアム化
```

## 技術スタック

| コンポーネント | 技術 | 選定理由 |
|----------------|------|----------|
| フレームワーク | React Native / Expo | MUEDnoteと共通化、クロスプラットフォーム |
| オーディオ | expo-av | 音声再生のみ、複雑な処理不要 |
| 状態管理 | Zustand | 軽量、MUEDnoteと同じ |
| 広告 | Google AdMob (react-native-google-mobile-ads) | リワード広告対応、業界標準 |
| 課金（将来） | Expo IAP / RevenueCat | クロスプラットフォーム対応 |
| 分析 | Firebase Analytics | 無料、十分な機能 |
| バックエンド | なし（ローカル完結） | インフラコスト最小化 |

### プラットフォーム

| プラットフォーム | 対応 | 備考 |
|------------------|------|------|
| iOS | ◎ MVP | メイン |
| Web | ○ 将来 | PC対応、Expo Webで出力可能 |
| Android | △ 要望次第 | 後回し |

## 音源制作

### ワークフロー

1. Suno AIでベーストラック生成（カテゴリごとに10-20ループ）
2. DAWで加工してバリエーション作成（EQブースト/カット、コンプ、リバーブ等）
3. 最適化して書き出し（MP3/AAC、128-192kbps）
4. アプリにバンドル（ストリーミング不要）

### 想定アセット数

| ゲーム | ベース | バリエーション | 合計ファイル |
|--------|--------|----------------|--------------|
| MuFreQ | 10 | 8周波数帯 × 各 | 80 |
| MuComp | 10 | 2（コンプ有/無） | 20 |
| MuRush | 10 | 8周波数帯 × 各 | 80 |
| MuVerb | 10 | 4リバーブ種 × 各 | 40 |
| MuWidth | 10 | 5幅レベル × 各 | 50 |

**合計: 約270ファイル**

## ビジュアル・ブランディング

### Hooのデザインコンセプト

Hooは3つの要素を組み合わせたデザイン：

1. **フクロウ** - 動物界最高の聴覚を持つ
2. **知恵** - フクロウの象徴
3. **アナログテープレコーダー（オープンリール）** - 目の部分が2つのリールを表現

### カラーパレット

| 色 | カラーコード | 用途 |
|----|-------------|------|
| ゴールド/アンバー | #F5A623 | アクセント、Hooの目 |
| セージグリーン | #7D9B76 | サブカラー |
| ベージュ | #F5E6D3 | ライト背景 |
| ダークグレー | #2D2D2D | ダーク背景 |
| チャコール | #3D3D3D | テキスト |
| オフホワイト | #FAFAFA | ライトテキスト |

### スタイル

- フラットイラスト / ベクターアート
- ノイズ/グレインテクスチャあり
- 限定カラーパレット
- 温かみのあるレトロモダン
- プロフェッショナルだが親しみやすい
