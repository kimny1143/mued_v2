## P0: 今日やる（明日Threads投稿でトラフィック来る前に）

### 1. メタタグが全部 MUEDnote になっている

**現状（ブラウザで確認済み）:**
```
<title>MUEDnote - 制作のそばに、いつもHoo。</title>
<meta name="description" content="音楽制作のおともアプリ。休憩のタイミングを教えてくれて、音に反応して動く。声でメモを残すと自動で文字起こし。">

<meta property="og:description" content="音楽制作のおともアプリ。休憩のタイミングを教えてくれて...">
<meta property="og:image" content="https://mued.jp/og-image.jpg">
```

**修正後:**
```
<title>MUEDial — ミックス、フェーダーに触らなくていい。</title>
<meta name="description" content="ステムを上げて、AIと話すだけ。おまかせミックス$12から。スライダーもプラグインもなし。チャットでミックスが仕上がる。">
<meta property="og:title" content="MUEDial — ミックス、フェーダーに触らなくていい。">
<meta property="og:description" content="ステムを上げて、AIと話すだけ。おまかせミックス$12から。">
<meta property="og:image" content="（MUEDial固有のOG画像。Hooがミキシングコンソールにいるやつ等）">
```

Next.js App Router なら `app/dial/page.tsx` の `metadata` export か `generateMetadata` で設定。親 layout からの継承で MUEDnote のメタが来ている可能性が高い。`app/dial/page.tsx` で明示的に上書きすること。

**影響:** Google検索結果、SNSシェアカード（Threads/LINE/Twitter）、ブラウザタブ表示が全て間違った製品名になる。

### 2. CTAボタンが disabled で理由がわからない

**現状:**
- 「サービスを選択」ボタンが `disabled: true`
- プラン未選択 + メール未入力だと有効化されない
- しかし **なぜ押せないのか一切表示されない**
- ボタンのグレーアウトも視覚的に弱く、無効状態と気づきにくい

**修正（いずれかを実装）:**

案A（推奨）: **「おまかせミックス $12」をデフォルト選択にする**
- 初期状態で一番安いプランが選択済み
- メール入力 → 即CTA可能
- コンバージョンまでのステップが1つ減る

案B: **ボタン下にガイドテキスト表示**
- 未選択時: 「↑ プランを選んでメールアドレスを入力してください」
- プラン選択済み・メール未入力時: 「メールアドレスを入力してください」
- 両方入力済み: テキスト消去、ボタン有効化

## P1: 今週中

### 4. デモ音源の Before/After

**現状:** 「デモ音源 準備中」と表示。Before/After のプレーヤーは存在するが再生できない。

**対応:** ミキシングサービスで音が聴けないのは致命的。実際の MUEDial ミックス結果で Before（素のステムミックスダウン）/ After（AI ミックス後）を用意する。1曲で良い。

準備できるまでの暫定対応: セクション自体を非表示にする。「準備中」を見せるより何もない方がマシ。

### 5. USD 横に日本円目安を追加

**現状:** `$12` / `$35` / `+$5` のみ。ページは全文日本語。

**修正案:**
```
おまかせミックス  $12（約1,800円）
対話ミックス      $35（約5,300円）
+$5 マスタリング （約750円）
```

為替レートをハードコードで良い。「約〇〇円」表記で。Stripe決済時に正確な金額が出るのでここは目安で十分。

## P2: 来週以降

### 6. CTAラベル改善

「サービスを選択」→「ミックスを始める」or「注文に進む」

プランはその上のカードで既に選んでいる。ボタンは次のアクションを示すべき。

### 7. FAQ セクション追加

CTA の下（Before/After の前あたり）に簡易FAQ:

- **どんなファイルが必要？** → ステム（各トラックの書き出し）。WAV/AIFF推奨、MP3も可。
- **納期は？** → おまかせ: 数分〜。対話: 会話しながらリアルタイム。
- **対応ジャンルは？** → ジャンル制限なし。ポップス、ロック、EDM、ヒップホップ等。
- **やり直しできる？** → 対話ミックスはセッション中に何度でもリテイク可能。

### 8. email input に `required` 属性を追加

現在 `required: false`。HTML5 バリデーションが効かない。
