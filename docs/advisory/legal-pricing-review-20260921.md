# advisory 新料金の法定表示確認（2026-09-21・PR #1069）

旧3段の販売終了・新体系への切り替えは kimny 裁定。対象は小規模事業者。新しい解約権・残額支払義務・返金方法をこの修正で決定しない。未確定条件は `[kimny 確認]`（英語では `[kimny confirmation]`）として翻訳本文にも残す。以下の回答を得て表示を確定するまで、販売開始・法定表示確認完了とは扱わない。

## 確認事項

- **[kimny 確認: 支払方法は請求書/銀行振込で確定か・分割の回数と時期]**。請求書（銀行振込）は想定であり確定ではない。`tokushoho.payment.value` の advisory 行と `tokushoho.advisory.paymentTiming.value` の先頭行には、同一の未確定表現を置いた。有料3メニュー共通の表示。
- **[kimny 確認: 3ヶ月プログラムの分割の回数・各回の金額と支払期日、一括払いの場合の支払期日]**。月額100,000円（税込110,000円）・総額300,000円（税込330,000円）・分割可は確定。これだけを根拠に分割回数や支払日を確定しない。
- **[kimny 確認: 3ヶ月プログラムの着手前キャンセル・中途解約の可否]**。可とする場合は、提供済み役務・作成済み成果物・発生済み外部費用の精算方法、支払済額の返金方法、未払残額の扱い・支払期日も確認する。旧単発診断の精算条件を自動で引き継がない。
- **[kimny 確認: スポット相談料の支払期日]**。都度請求を明記し、役務提供の前後を推測で補わない。

## 射程と検証

- 今回の補正: `messages/{ja,en}.json`、`tests/unit/advisory-pricing-locales.test.ts`、本書。前の価格修正は `app/llms.txt/route.ts` も対象（`/llms.txt` の実体）。特商法ページの表示構造や他サービスの支払方法は変更しない。
- messages は対象の文字列だけを置換し、JSON formatter を使わない。キーを追加・削除せず、日英の全キー集合が一致することをテストする。
- RETIRED_PRICES は税抜・税込の6数: `250000 / 275000 / 200000 / 220000 / 400000 / 440000`。`30000` は新スポット・お守りプランで使用するため含めない。
- 日英の全 namespace、llms.txt のソース全体・HTTPハンドラー応答を検査。カンマ・空白を除去して旧6数の残存を検出し、新価格がページの参照する特商法表示行に存在することも検査する。
- テストは支払方法の2箇所一致、メニュー別の支払・提供・解約条件、未確定の分割・中途解約・残額の確認表示を検査する。これは法的適合性や未確定条件の承認を証明するものではない。
- meta-RED（旧特商法文言への差し戻しによる失敗確認）は mued 課の検収担当。Codex は本補正でその検収を代行しない。
