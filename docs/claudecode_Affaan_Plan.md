     2. ギャップ分析

     高優先度の欠落

     1. カスタムスラッシュコマンド - ワークフロー効率化の要
     2. code-reviewer エージェント - PRレビュー自動化
     3. TDDスキル - テスト駆動開発の標準化
     4. プロジェクトレベルMCP設定 - チーム共有・コンテキスト管理

     中優先度の欠落

     5. security-reviewer エージェント - セキュリティ監査
     6. PreToolUseフック - 事前検証
     7. disabledMcpServers設定 - 不要MCPの無効化

     低優先度（あれば便利）

     8. Rules（常時適用ルール） - スキルとは別の基本ルール
     9. backend-patternsスキル - APIパターン標準化

     ---
     3. 改善提案

     フェーズ1: コマンド追加（即効性高）

     .claude/commands/ に以下を追加:
     - commit.md - コミット・プッシュ・PR作成
     - tdd.md - TDDワークフロー実行
     - review.md - コードレビュー実行
     - build-fix.md - ビルドエラー修正ループ

     フェーズ2: エージェント追加

     .claude/agents/ に以下を追加:
     - code-reviewer.md - PR/コードレビュー専門
     - security-reviewer.md - セキュリティ監査専門

     フェーズ3: MCP設定整備

     .mcp.json をプロジェクトルートに作成:
     - GitHub MCP（PRコメント対応）
     - 使用MCPの明示化
     - disabledMcpServers設定

     フェーズ4: フック強化

     PostToolUse フック追加:
     - console.log検出・警告
     - 未使用インポート検出
