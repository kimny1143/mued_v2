## 4. ★MUEDnote / サブスクの解約（⑨・★返金ではない）

★**Stripe で「請求期間の終了時にキャンセル」を選ぶ。「即時キャンセル」を選ばない。**

★**実測**: ★**`cancel_at_period_end: true` を Stripe へ送っている箇所は★リポジトリ全体で 0件**（webhook の 13箇所は**受信値の DB 保存**・`subscriptions.repository.ts:599` は**自社 DB の UPDATE**）。
∴ ★**どちらを選ぶかは★完全に人の操作に依存する。★コードは止めてくれない。**

★**「即時」を選ぶと開示が2箇所 同時に偽になる**（④＝期間終了まで使える／⑤＝残クレジット30日の起点が早まる。詳細は `tokushoho-operational-obligations.md` §2）。
