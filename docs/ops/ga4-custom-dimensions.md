# GA4: このプロパティには custom dimension が1件も登録されていない

- **測定**: 2026-08-04 / mued（GA4 Data API 実測）
- **対象**: GA4 property `525457895`
- **なぜ書くか**: ★**次に event param ベースの計測を足す人が、同じ所で止まらないため。**

---

## 0. 結論（★1段落）

★**`gtag` で送っている event param は、custom dimension として登録するまでレポートでも Data API でも引けない。** そして★**このプロパティには 2026-08-04 時点で custom dimension が 0 件登録されている。**

∴ ★**「param を送る実装を入れた」＝「その値が読める」ではない。** **送る側だけ作って登録を忘れると、値は正しく届いているのに誰も見られない状態になる。**

## 2. ★確定していないこと — 遡及の可否

★**「登録後に届いたデータにしか遡及しない」は、当課が一般知識から書いたもので、一次で裏付けられていない。**

**確認した Google 公式ヘルプ2本は、どちらも遡及について明示していない**:

| doc | 書いてあること |
|---|---|
| `support.google.com/analytics/answer/10075209` | 「**After 24-48 hours, you can start to report on…**」＝**利用可能になるまでの時間**のみ |
| `support.google.com/analytics/answer/14239696` | 「**カスタムデータが送られ かつ custom dimension が作成されてから 24-48時間 後に、任意のレポートへ追加できる**」のみ |

★**「遡及しない」と書いてある文は見つかっていない。** **「見つからなかった」であって「遡及する」ではない。**

### ★それでも「先に登録する」で良い理由（両分岐を見た）

| 仮に | 早く登録 | 遅らせる |
|---|---|---|
| **遡及する** | 損なし | 損なし |
| ★**遡及しない** | その間のデータが読める | ★**その間のデータは永久に読めない** |

★**両分岐が同じ向きを指すので、遡及の可否が未確定でも判断は変わらない。** ★**ただし理由の書き方は分けること**——**「読めない」は測れているが、「取り返せない」は測れていない。**

### ★この未確認を潰す方法（登録後に1回）

★**登録が済んだら、登録より前の期間を指定して `customEvent:<name>` を引く。** **行が返れば遡及する／0行なら遡及しない。** **登録は GA4 の編集者権限（kimny 手番）なので、それまでは測れない。**

## 4. 既知の未修正（この文書の発端）

**`lib/analytics/gtag.ts:54`**:

```js
destination: product === "muedial" ? "external_site" : "app_store",
```

★**`trackCtaClick` の call site 5件のうち `'muedial'` を渡しているものは 0 件**（product課 実測）＝**`external_site` は到達不能な死枝で、`cta_click` は全件 `destination: "app_store"` が付く**。★**実際にはどれも App Store へは行かない**（web の LP・waitlist・サインアップ）。

★**修正 PR は登録が済んでから出す。** **先に出すと「正しい値が書かれているが誰にも読めない」を自分で作る。**

★**注意**: `product === "muedial"` は等値比較なので、`startsWith('muedial')` に変えるだけでは `waitlist_from_readiness`（**MUEDial ですらない**）が救われない。**呼び出し側から明示的に渡すのが素直**（product課）。
