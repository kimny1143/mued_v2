## 4. D&B認証完了後のタスク

### 即実行可能

```bash
# 1. Apple Developer登録完了確認

# 2. eas.json にApple情報追記
# apps/muednote-mobile/eas.json の submit.production を編集:
{
  "submit": {
    "production": {
      "ios": {
        "appleId": "YOUR_APPLE_ID",
        "ascAppId": "APP_STORE_CONNECT_APP_ID",
        "appleTeamId": "YOUR_TEAM_ID"
      }
    }
  }
}

# 3. EASビルド
cd apps/muednote-mobile
eas build --platform ios --profile production

# 4. TestFlight申請
eas submit --platform ios --profile production

# 5. テスターを招待
# App Store Connect > TestFlight > 内部テスト
```

### 工数目安

| タスク | 時間 |
|-------|------|
| eas.json編集 | 5分 |
| EASビルド待ち | 10-30分 |
| TestFlight申請 | 5分 |
| Apple審査待ち | 1-24時間 |
| **合計** | **30分〜数時間（審査除く）** |
