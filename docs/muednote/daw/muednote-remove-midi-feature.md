# MUEDnote DAW連携：MIDI取得機能の削除指示

## 概要

MUEDnoteのDAW連携機能から、MIDI情報取得に関する実装を削除する。

## 削除理由

### 1. 価値の低さ（二重保存問題）

DAWに録音されたMIDIデータは「DAWの中にある」ため、MUEDnoteが外部から取得して二重に保持する意味がない。

- 録音されたMIDIは既にDAWプロジェクトに保存される
- MUEDnote側で複製を持つ必然性がない
- ストレージ・通信コストに見合う価値がない

### 2. OSCパラメータとの価値差

| データ種別 | DAWに残るか | MUEDnoteでの価値 |
|-----------|------------|-----------------|
| OSCパラメータ変化（EQ、コンプ設定等） | 残らない | **高い**（操作履歴として唯一の記録） |
| MIDIノート情報 | 残る | **低い**（DAWとの重複） |

### 3. ログ量問題

MIDIを全取得すると1時間で最大12万件のイベントが発生。サーバー負荷・ストレージコストに対してリターンが見合わない。

### 4. プライバシー・知的財産リスク

演奏データの取得・蓄積は、プロユーザーにとって知的財産流出の懸念材料となる。OSCパラメータ（操作履歴）に限定することで、この懸念を回避できる。

## 削除対象

以下のMIDI関連実装を削除する：

### コード

- CoreMIDI / IAC Driver 経由のMIDI受信処理
- MIDIイベント（Note On/Off、CC）のログ記録処理
- Transport状態によるMIDI取得ON/OFF制御
- MIDI関連のAPIエンドポイント
- MIDI関連のDBスキーマ・テーブル（あれば）

### ドキュメント

- MIDI取得に関する設計書・仕様書の該当セクション
- README等のMIDI機能に関する記述

### 設定

- MIDI関連の環境変数・設定項目
- MIDI入力デバイス選択UI（あれば）

## 残す機能

以下はそのまま維持：

- AbletonOSC経由のパラメータ変化取得
- Transport状態の取得（再生/停止/録音の検知）
- プラグインパラメータの変化ログ
- トラック操作（Mute/Solo等）のログ

## 今後の方針

- MIDI取得は現時点では実装しない
- ユーザーから明確な要望があった場合に再検討
- 再検討時は「Transport停止中のみ取得」に限定する設計とする

## 参考：もし将来MIDI対応する場合の制約条件

```
Transport停止中 → MIDIログ取得ON
再生 or 録音中 → MIDIログ取得OFF（スキップ）
```

「録音ボタン押す前の試行錯誤」のみを対象とし、録音中のデータは取得しない。ただし、現時点ではこの実装も不要。
