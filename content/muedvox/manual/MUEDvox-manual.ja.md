# MUEDvox ユーザーマニュアル（1.1.0）

MUEDvox は、メインボーカル 1 本から、歌い方の違うハーモニーを作るプラグインです。声部ごとに「どの音程で」「どんな声で」歌うかを決められます。

## 1. インストールとライセンス

### Mac（AU・VST3・AAX）
1. DAW を終了します。
2. `MUEDvox-1.1.0-installer.pkg` を開き、画面に従います（管理者のパスワードが要ります）。
3. DAW を開き、プラグインを再スキャンします。

アンインストールは `/Applications/MUEDvox/Uninstall MUEDvox.command` を開きます。ライセンスキーは消えません。

1.0.0・1.0.1・1.0.2 から更新する時は、上から入れ直します（Mac は新しい pkg を開く・Windows は `MUEDvox.vst3` フォルダーを置き換える）。ライセンスキー・プリセット・セッションはそのまま使えます。

### Windows（VST3・64 bit）
1. DAW を終了します。
2. ZIP を展開し、中の `MUEDvox.vst3` フォルダーを `C:\Program Files\Common Files\VST3\` にコピーします（展開でできた外側のフォルダーごとではなく、`MUEDvox.vst3` だけ）。
3. DAW を開き、VST3 プラグインを再スキャンします。

### 画面の大きさ
画面の右下の隅をドラッグすると、全体を拡大・縮小できます（50〜400 %）。Windows では、開いた時に画面に収まる大きさ（100／75／60／50 % のどれか）で始まります。変えた大きさは、画面を閉じて開き直すだけなら残ります。プラグインを挿し直した時と、セッションを開き直した時は、最初の大きさに戻ります。

### ライセンスキー
キーが無い間はデモです（期限はありません）。**音を 45 秒鳴らすごとに、ハーモニーが 3 秒ほど抜けて、また戻ります。元の歌（Lead）は鳴り続けます。** 書き出しにも抜けが入ります。デモで作った設定はセッションに保存され、キーを入れた後もそのまま開けます。MUEDvox のプリセットメニューからの保存（Save preset…）はキーを入れてからです。DAW の機能で保存するプリセットは、デモでも使えます（7 章）。デモの間、画面の右下には **DEMO · ENTER LICENSE** と出ます。

キーを入れるには、画面の右下の表示（DEMO）をクリックして小窓を開き、次のどれかを行います。
- ライセンスファイルを小窓にドロップする
- **Load license file…** でファイルを選ぶ
- キーの文字をコピーして **Paste from clipboard**

入ると表示が **LICENSED** に変わり、ハーモニーが戻ります。キーは 1 度入れれば、同じユーザーで開くすべての MUEDvox に効きます。

試用のライセンス（期限のあるキー）では、期限まですべての機能が使えます。期限が過ぎるとデモに戻ります。どちらの場合も、セッションの設定はそのまま残ります。

## 2. 最初の使い方

1. ボーカルのトラックに MUEDvox を挿します。ボーカルは 1 人の声・和音でない素材が向いています。
2. 右の **SCALE** で曲の Key とスケールを選びます。
3. 再生します。既定では、3 度上（V1・falsetto）と 3 度下（V2・mix）が鳴ります。
4. 右上の **Lead** と **Harmony** で、元の歌とハーモニー全体の音量を決めます。

## 3. Mode — 音の良さと遅れの選び方

上の帯の **MODE** で選びます。数字はプラグインの遅れ（レイテンシー）で、DAW に報告されます。

- **Render（0.94 秒）** — いちばんきれいな音です。先の音を読んでから歌うので、0.94 秒遅れます。Pro Tools ではこの遅れが遅延補正の上限を超えるため（トラックの Delay の数字が赤くなります）、そのままでは他のトラックより遅れて聞こえます。**トラックをコミットして使ってください。** コミットした音は元の歌と位置が合います。ほかの DAW で遅れて聞こえる時は、トラックをフリーズまたはバウンスしてください。
- **Track（0.34 秒）** — Render に近い音で、遅れは 3 分の 1 です。Pro Tools の遅延補正の範囲に収まるので、インサートに挿したままミックスできます。48 kHz では上限のほぼ一杯なので、同じトラックに遅れのあるプラグインを重ねないでください。
- **Live（3 ms）** — 歌いながら、弾きながら使うモードです。ほぼ遅れません。音の質は Render・Track に及びません。

Render の時は、鍵盤の上に遅れの注意が 1 行出ます。**Details >** をクリックすると、3 つのモードの説明が開きます。

右上の **ACTIVE** を切ると、プラグインは何もせず音を通し、遅れも 0 になります。

## 4. 声部（V1〜V4 と Bass）

画面の左の 5 本の列が声部です。

- **ON** — その声部を鳴らします。
- **S・M・W** — ソロ、ミュート、W はその声部を息の成分だけ（ささやき）にします。
- **音程（◀ ▶）** — 元の歌からの度数です。+2 は 3 度上、−2 は 3 度下、+4 は 5 度上。スケールに沿って動きます（Scale が Chromatic の時は半音で数えます）。
- **REGISTER** — 声区のレバーです。上から CHEST（地声）・MIX・HEAD・FALSETTO（裏声）・WHISPER。同じ音程でも、歌い方を変えられます。
  - **SAFE** が点いている間は、WHISPER の端（不自然になりやすい範囲）へは動きません。クリックして外すと、端まで動かせます。
- **LEVEL** — その声部の音量。
- **PAN** — 左右の位置。
- **DOUBLE** — 声部を 2 人で歌っているように重ねる量。
- **Detail ▸** — 声部ごとの細かい調整（Formant、Low cut、High cut、Mud）。

**Bass** は低い声部です。**Octave** は元の歌の 1 オクターブ下、**Chord** は和音の低音を歌います（MIDI の和音が要ります）。

### MASTER・STEREO FIELD
右上の半円は、各声部の左右の位置と音量の図です。声部の丸をドラッグすると、向きが Pan、中心からの距離が Level になります。

### CHORUS と CLEAN
- **CHORUS** — ハーモニー全体に掛かる広がり（I・II・I+II、DEPTH、MIX）。
- **CLEAN** — オンにすると、ダブル・コーラス・声部の EQ を外し、ハーモニーと声区だけの素の音にします。高域のざらつきが気になる時に試してください。

## 5. スケールと和音

- **SCALE** — Key とスケールの名前を選びます。12 個の音名をクリックすると自分のスケールを作れます（名前は Custom になります。Key とスケールはセッションに保存され、プリセットでは変わりません）。
- **Follow MIDI chords** — オンの時、MUEDvox に送った MIDI の和音にハーモニーが従います。和音はどのオクターブで弾いても同じです（音名で読みます）。MIDI が来ていない間は、スケールに従います。
  - MIDI の送り方は DAW によります。Pro Tools では、MIDI またはインストゥルメントのトラックの出力に MUEDvox を選びます（**MIDI チャンネル 1** で送ってください）。
  - Logic Pro では、ソフトウェア音源トラックを作り、その音源の枠に **AU MIDI-controlled Effects**（英語の表示の名前）から MUEDvox を挿します。プラグインの窓の上の **Side Chain** で歌のトラックを選び、和音の MIDI はそのソフトウェア音源トラックに置きます。**歌のトラックはミュートしてください**（ミュートしても Side Chain には音が届き、元の歌は MUEDvox の Lead から鳴ります）。
- **Avoid parallel 5ths** — 声部が元の歌と平行 5 度で動くのを避けます。
- 画面の下の **KEYBOARD** は表示だけです。届いている MIDI と、鳴っている声部の音が見えます。左上に **Save MIDI…** があります（9 章）。

## 6. FX のページ

上の帯の **HARMONY｜FX** で切り替えます。エフェクトは元の歌を含む全体に掛かります。

Program EQ、Comp、Sat、Delay、Reverb、Chorus、Flanger、Phaser、Imager の 9 つ。使う物をラックに載せ、ドラッグで順番を入れ替えられます。Delay にはテンポ同期（付点・3 連）、Ping Pong、L/R 別の時間、Diffuse（反射を拡散させる）、HPF／LPF があります。

## 7. プリセット

上の帯の **PRESET** から選びます（◀ ▶ で順に送れます）。プリセット 1 つが、ハーモニーの設定（声部・コーラスなど）と FX のページの設定の両方を持ちます。HARMONY と FX のどちらのページでも同じ一覧です。

- 最初から 7 つ入っています: Natural・Clean・Wide Stack・Stack + Bass・Vintage Chorus・Plate Duo・Wide Duo。
- **Save preset…** で、今の設定に名前を付けて保存できます。自分のプリセットは **Delete** で消せます（確認は出ません）。
- デモの間は **Save preset…** が灰色で「(needs a license)」と出ます。プリセットを選ぶ・消すことはできます。
- DAW の機能で保存するプリセット（VST3・AU のプリセットや Pro Tools のプラグイン設定など）は、キーの有無にかかわらず使えます。こちらはプラグインの全部（Key とスケールを含む）を保存します。
- FX は元の歌（Lead）にも掛かります。リバーブやディレイの入ったプリセットを選ぶと、Lead にも付きます。

**プリセットで変わらないもの**: Key とスケール（曲のもの）・Mode・ACTIVE・SETTINGS の中身。これらはセッションに保存されます。

## 8. SETTINGS

画面の右上、ACTIVE のすぐ左の**歯車**を押すと **SETTINGS** が開き、Live モードの動きの設定が 2 つあります。箱の外か、もう一度歯車を押すと閉じます。セッションに保存され、プリセットでは変わりません。
- **Note start** — ハーモニーの音がどれだけ早く出るか（Soft・Fast・Fast+）。早いほど出だしは速く、音程の読み違いは増えます。
- **Chord change under a held note** — 伸ばしている歌の途中で和音が替わった時、すぐ従う（Follow）か、次の歌の音まで待つ（Hold）か。

## 9. ハーモニーを MIDI に保存する

ハーモニーの声部が歌った音を、声部ごとのトラックの MIDI ファイルに書き出せます。譜面にしたり、直したり、別の音色で鳴らしたりできます。

1. Mode を **Render** か **Track** にして、曲（または使いたい所）を再生します。DAW が再生している間、聞こえている声部の音が溜まります。鍵盤の左上の数（「N notes · N passes」）が増えます。
2. **Save MIDI…** を押し、名前と場所を選びます。ファイルは Standard MIDI File（type 1）です。声部ごとに 1 トラック（MUEDvox V1〜V4・MUEDvox Bass）で、曲のテンポと拍子が入ります。
3. DAW に、曲の頭（1 小節目）に合わせて入れます: ファイルをアレンジに drag するか、読み込みます（Pro Tools は File > Import > MIDI）。音は歌った小節の位置に来ます。

溜まる物:
- 各声部が歌う音を、MUEDvox が割り当てた高さ（スケール、または Follow MIDI chords が on の時は和音）で、歌の音の始まりから終わりまで。しゃくりやビブラートなど歌の揺れは入りません。
- 聞こえている声部だけです。off・ミュート（M）・ソロの外の声部は溜まりません。Harmony を消している間も溜まりません。Live モードの時と、DAW が止まっている間も溜まりません。
- 同じ小節をもう一度再生すると、その小節は置き換わります（新しい方を残す・そこで音が無くても）。ループは最後の周が残ります。
- 音の頭の短いしゃくりと終わりの短い落ち（0.1 秒未満）は、その音に含めます。速い節回しや短い言葉はそのまま残ります。
- **Clear** で、それまで溜まった物を全部消します。

デモでは **Save MIDI…** は灰色で「(needs a license)」と出ます。

## 10. うまくいかない時

| 起きている事 | 見る所 |
|---|---|
| ハーモニーが 45 秒ごとに数秒抜ける | デモです。ライセンスキーを入れてください（1 章）。 |
| Save preset… が灰色 | デモです。ライセンスキーを入れるか、DAW の機能でプリセットを保存してください（7 章）。 |
| 他のトラックより遅れて聞こえる | Mode が Render の時は、トラックをコミット／フリーズ／バウンスするか、Track に替えます（3 章）。 |
| Pro Tools でトラックの Delay が赤い | Render の遅れが遅延補正の上限を超えています。コミットすれば位置は合います。 |
| 和音に従わない | Follow MIDI chords がオンか・MIDI が MUEDvox に届いているか（鍵盤の表示に出ます）・Pro Tools ではチャンネル 1 か。 |
| 高域がざらつく | CLEAN をオンに、または DOUBLE を下げます。REGISTER を WHISPER の端から離します。 |
| Live で音程が跳ぶ | SETTINGS（歯車）の Note start を Soft に。Live は 1 人の声・伴奏の混ざらない素材向きです。 |
| Save MIDI… に音が溜まらない | Mode は Render か Track か・DAW は再生しているか。Harmony は on か・声部は on でミュートされていないか。鍵盤に「No song position from the host」と出ていたら、DAW が曲の位置を plug-in に渡していません。 |
| MIDI ファイルの音が小節とずれる | 再生位置ではなく、曲の頭（1 小節目）に合わせて入れてください。 |
| Logic でインサートに MUEDvox が無い・和音を送れない | ソフトウェア音源トラックの音源の枠に AU MIDI-controlled Effects から挿し、Side Chain で歌のトラックを選びます（5 章）。 |
| Logic で元の歌が 2 重に聞こえる | 歌のトラックをミュートします。Side Chain には音が届きます（5 章）。 |
| Pro Tools の AudioSuite に出ない | AudioSuite には対応していません。インサートで使い、Render はコミットしてください。 |
